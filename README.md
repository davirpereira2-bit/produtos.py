# produtos.py

#  Product Selector System - Python

###  Descrição
Módulo de seleção de produtos desenvolvido para simular o menu de um sistema de vendas. Focado em mapeamento de variáveis e estruturas condicionais encadeadas.

###  Funcionalidades
- **Menu Interativo:** Apresentação de opções numeradas para facilitar a experiência do usuário.
- **Mapeamento de Atributos:** Atribuição dinâmica de nome e preço com base na escolha do cliente.
- **Tratamento de Exceções Lógicas:** Filtro para opções inexistentes no cardápio.

### Conceitos Aplicados
- **Condicionais Encadeadas:** Uso de `if/elif/else` para múltiplos caminhos de decisão.
- **Formatação de Dados:** Saída monetária padronizada.
